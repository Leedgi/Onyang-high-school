# OCR 테스트 사진

실제 OCR 성능을 확인할 원본 사진을 이 폴더에 올려주세요.
지원 형식: JPG, JPEG, PNG, HEIC, HEIF.

## GitHub에서 올리는 방법

1. `samples/ocr` 폴더에서 **Add file → Upload files**를 선택합니다.
2. 테스트 사진을 끌어 넣습니다.
3. **Commit changes**를 눌러 main에 저장하고, 채팅에 업로드했다고 알려주세요.

정방향 원본만 있어도 90·180·270도 회전 입력은 검사할 때 만들 수 있습니다.
곡면에서 실패하는 경우에는 용기의 곡면이 보이는 원본 사진도 함께 넣어주세요.
사진 이름은 자유롭게 정해도 됩니다.

## 정답 목록은 선택 사항입니다

성분 목록을 알고 있다면 사진과 같은 이름의 `.expected.txt` 파일을 함께 올려주세요.
성분 하나를 한 줄씩, 사진에 적힌 순서대로 적고 숫자·슬래시·괄호 주석을 유지하면 됩니다.

```text
sample01.jpg
sample01.expected.txt
sample02.heic
```

사진만 먼저 올려도 괜찮습니다. 원본 사진의 인식 결과와 검사 때 만든 회전·곡면 변형 결과를 구분하고,
누락된 이름·잘못 읽은 이름·처리 시간을 비교하겠습니다.

## 현재 제공된 42장 검사

현재 14개 제품의 실제 촬영 사진 42장이 있다. 최상위에 있던 JPG 12장도 이 폴더로 이동했다.
`expected/`의 14개 TXT는 사진을 직접 대조해 옮긴 한글 성분명 정답이며,
`manifest.json`이 각 제품의 세 사진을 같은 정답에 연결한다. 함량 주석은 사진 원문에 보존하고
이름 단위 평가와 구별한다. 검사 결과와 정답의 오타를 발견하면 함께 수정해 다시 비교한다.

```bash
python -m scripts.check_real_ocr --workers 2
python -m scripts.check_real_ocr --front-only
python -m scripts.check_real_ocr --files 20261029_224822.jpg
```

기본 출력은 `artifacts/real-final/report.json`이다. 정답과 정확히 일치하는 성분명을 기준으로
정밀도(읽은 목록 중 맞은 비율), 재현율(실제 목록 중 찾은 비율), F1을 모두 기록한다.
유사도 점수를 정답 확률로 세지 않는다. 교정 제안도 사용자 확인 전 목록이다.
평가 파일은 OCR 추론에서 읽지 않으며 사진을 외부 AI로 보내지 않는다.
