# 주의·인체·생분해성 DB 1차 검토

2026-10-30. B 자료 작업. 공개 함수와 CautionRecord 열은 유지했다.

입력은 사용자가 확정한 성분명이다. 기존 B 분석이 canonical_name과 주의 CSV를 대조해 출처·확인일·사용 조건을 반환한다. 모르는 이름은 자료 없음으로 남기며, 위험하거나 안전한 것으로 확정하지 않는다.

검토 범위는 30개 물질이다. AHA 3, BHA 1, 향료 16, 보존제/포름알데하이드 관련 7, 환경 시험 3이다. 한국어·INCI·검증된 구명칭과 정확한 물질명 표기를 포함해 런타임 주의 레코드는 63행이다. FDA 페이지 본문과 이름 목록, PubChem JSON의 물질별 시험과 참고문헌, KCIA INCI 검색 결과를 실제로 읽었다. 원문 일부·응답 SHA-256·명칭/CAS 대조·자료 시점과 확인일을 검토 입력에 남겼다.

생분해성 자료는 D4/D5/D6에만 적용한다. D4 3.7%(29일/10 mg/L), D5 0.14%(28일/20 mg/L), D6 4.47%(28일/농도 미기재)는 해당 시험의 지표다. 자연환경에서 모든 분해가 불가능하다거나 모든 실리콘이 유해하다고 확장하지 않는다. D4의 INCI 표기에는 여러 CAS, 리모넨에는 여러 이성질체가 연결되어 조건 확인을 안내한다.

자료와 결과 한계:

- FDA 알레르겐 페이지는 2026-10-09 갱신 표기, AHA/BHA는 2022 갱신 표기이다.
- PubChem/HSDB의 환경 시험 인용은 2015 ECHA 조회 기록, D6는 2008 캐나다 평가서에 바탕을 둔다. 이번 열람일이 새 시험 날짜는 아니다.
- ECHA 원사이트는 403, EUR-Lex는 본문 없는 202 응답으로 최신 법규를 읽지 못했다. 그 법규의 제한 농도·시행일을 만들어 넣지 않았다.
- 완제품 pH·함량·노출 조건을 알 수 없어 제품별 안전성·배출 위해성 점수는 계산하지 않는다.
- 데이터가 없는 이름과 메타데이터로 확인하지 못한 최신/다른 한글 표기는 자동 동의어로 추가하지 않았다. FORMALDEHYDE는 검증한 영문만 지원한다.

B 검사: 새 검토 대상의 경고 연결, 농도/국가/사용 조건, 이성질체·CAS 범위, 다른 실리콘/알 수 없는 이름에 오적용 방지, 시험 수치·기간·지표, 생성 재현성과 체크섬을 검사한다. C가 공통 로더에서 검증된 한글 동의어를 연결하고 DB 변경 시 결과를 무효화해야 완전 통합된다.
