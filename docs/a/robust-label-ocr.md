# 방향·곡면·후처리 재점검 (2026-10-31)

입력: 원본 사진과 고정 명칭 DB. 처리: 네 방향 비교, 약한 탐색 결과의 LSTM 방향 재검사, 원본 해상도 영역 보정, 전체 문단 인식과 줄별 곡면 대안 비교, 불확실한 실제 단어 픽셀의 두 로컬 OCR 교차 확인. 출력: 같은 ScanOutput/IngredientDraft의 미확정 목록. 실패: 모델 실패·인쇄 줄 추적 불완전·숫자 불일치를 구분하고 성공한 기존 경로를 보존한다.

기존 한 가지 약한 곡면 가설에 더해, 줄마다 곡선과 이웃 줄 사이 높이를 추정한다. 일부 짧은 마지막 줄도 포함하고 서로 다른 획을 같은 줄로 추적하면 합친다. 줄별 높이 변화를 보정한 영상을 단일 행 모드로 인식한다. 전체 문단 경로는 유지하며 이름 근거 수와 전체 텍스트 길이·OCR 점수로 비교한다. 근거가 같은데 점수만 조금 높아진 줄별 경로는 기존 경로를 대체하지 않는다. 원통 반지름 측정이나 지워진 글자 복원이 아니다.

띄어쓰기/줄바꿈/하이픈 후처리를 유지하고 쉼표만 있는 줄에서 생기던 IndexError를 고쳤다. 단일 행 인식의 native 단어 순서와 상자를 사용해 구두점이 별도 물리적 줄로 밀리는 것을 방지한다. 실제 단어 상자가 있으면 픽셀 재인식 범위를 더 정확하게 잡는다. 한 글자 교정 제안의 중복 후보·숫자를 검사하고, 다른 로컬 엔진도 같은 후보를 낸 제한된 경우만 ai_reread_proposed로 제안한다. 두 엔진이 같은 이름을 내더라도 confirmed=False다. 원문/원래 조각/두 재인식 결과를 보존한다.

좌표: 새 행 영상의 bbox는 선택된 행 영상/합성 캔버스의 픽셀이다. rows_in_source_image의 source는 행 보정 전의 준비된 ROI 영상이며 카메라 원본 좌표가 아니다. processing에 원래 준비 영상 크기와 선택 영상 크기, 행 추적과 배치 위치를 기록한다.

검증: Linux Python3.14 전체81개 pytest 및 서버 검사를 통과했다. 모의 입력 검사는 사진 정확도 자료가 아니다. 같은 준비 영상의 Tesseract 기본 결과는 Python3.12.14와3.14.8에서 같은 텍스트 SHA-256이었다. 이는 한 영상/같은 모델의 비교이며 사용자 PC에서 모든 런타임 차이가 없음을 보증하지 않는다. 직접 곡면 합성한 ROI의 별도 인식 단계 비교는 원문 이름15/26에서 줄별 보정 후21/26으로 늘었다. 전체 자동 파이프라인의 정방향/180/90/270/곡면/곡면180도 검사는 별도 실행 결과로 구분한다.

한계: 현재 대화에서 실패한 촬영 사진을 도구로 읽을 원본 파일 경로는 없다. 기존 인공 라벨과 명시적으로 합성한 변형을 검사하며 실제 촬영 사진의 일반 정확도로 주장하지 않는다. 새로운 의존성·모델·외부 사진 전송은 없다. 실제 Windows 검사는 통합 workflow 결과를 따로 보고한다.
