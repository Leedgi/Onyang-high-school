# 기본 기반 검증 기록

검증 날짜: 2026-10-25 (한국 시간). 실행 호스트는 Linux / Python 3.12 CPU다.
실제 Windows 호스트 검사 결과는 이 기록에 포함하지 않는다.

- A 입력·검토 함수, B 실제 DB·비율 함수, C Streamlit 화면·자동 연결·오류 복구, Git 브랜치 준비를 검사한다.
- 브랜치 준비 검사는 임시 로컬 bare 저장소에 main과 세 역할 브랜치를 실제 push한다. GitHub 권한 검사는 아니다.
- 화면 업로드 검사는 명시적인 모의 OCR을 사용한다. 자동 실행·확인 전 미분석·한 번 확인·후보 변경/사진 변경 무효화·세션 분리를 검사한다.
- 리우젤 19개 성분은 사진을 눈으로 옮긴 오류 주입 텍스트 회귀 사례다. 촬영 사진 OCR 성능 측정이 아니다.
- 실제 CPU 모델 검사는 `scripts.check_auto_ocr`의 별도 인공 전체 라벨 26개로 수행한다.
  사용자 화면에 이 인공 예시를 넣지 않는다. 인공 이미지 한 장의 결과를 일반 정확도로 표현하지 않는다.

실행 결과:

- `python -m pytest -q`: 새 기본 프로젝트 **31개 통과**.
- `python -m scripts.check_server`: 실제 Streamlit HTTP health와 페이지 응답 통과.
- `python -m scripts.check_auto_ocr`: 실제 모델 실행 통과. 인공 라벨 26개 중 전체 사진 기존 인식 7개,
  자동 보정 OCR 이름 21개, 미확정 교정 제안 포함 24개 일치. 두 이름은 여전히 틀리므로 완벽한 인식이 아니다.
- 모델 가중치는 검증 환경의 기존 캐시를 재사용했다. 다운로드 파일이나 캐시 경로를 배포 ZIP에 포함하지 않는다.
- 기존 참고 프로젝트도 독립적으로 전체 191개 테스트를 다시 실행해 통과했다.
- 실제 GitHub 새 저장소는 주소가 아직 없으므로 생성·접속·push하지 않았다. 원격 작업을 완료했다고 주장하지 않는다.
