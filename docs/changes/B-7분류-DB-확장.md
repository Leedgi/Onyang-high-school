# B: 첨부 DB 확장과 C 연결 요청

사용자가 제공한 원본 CSV/JSON 11개와 7분류32797행 검토표를 가져왔다.
origin_taxonomy_sources.json은 가져온 파일의 SHA, 현재 기본 DB SHA, 행·범주·신뢰도 집계를 고정한다.
이름 기반 추정을 기존 origin의 확정 유래로 승격하지 않는다. 7분류와 confidence/source를 별도 필드로 전달하고
B가 같은 확정 목록의7분류 비율을 계산한다. 기존4분류 origin/count_ratio 및 검토6143/이름전용26654 집계는 유지한다.
C는 후방 호환 필드·v2 계약, 선택적 로더, 그래프/표/PDF의 추정 표시와 DB 변경 무효화를 연결한다.
기존 OCR·의존성·모델·환경 설정은 바꾸지 않는다. 추가 AHA3행은 원문 조건을 보존하고 체크섬/중복을 검증한다.
