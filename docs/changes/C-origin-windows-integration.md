# Windows 검사와 추가 유래 통합

2026-10-30. Windows 줄바꿈 수정 PR5(79f6549, main807a446)와 B의 추가 근거343b155/ab04dd4를 통합한다. 공개 함수·자료형·CSV 열·enum·CONTRACT_VERSION=1을 유지한다. 원래 확인 필요인 정식명만 보완하며 확정 유래·별칭 덮어쓰기를 거부한다. 원본·검토 입력 체크섬이나 집계가 다르면 오류 및 이전 결과/PDF 제거. 사용자 사진·확정 목록은 세션에만 둔다.

입력: 확인된 명칭과 고정 정의 근거. 처리: 근거 규칙·체크섬 검사와 제조 경로 안내. 출력: 동일 AnalysisResult의 유래 그룹/그래프/주의/PDF. 실패: 자료 검증 오류를 알리고 이전 결과를 사용하지 않는다. 근거 없는 후보 경로는 origin_uncertain으로 남겨 확정 비율에 섞지 않는다.

CSV/JSON은 LF, 배치 파일은 CRLF로 고정했으며 검증을 끄지 않았다. 이 후속 통합 PR에서도 Windows workflow를 실행한다. 결과는 해당 실행 링크와 구분해 보고한다.
