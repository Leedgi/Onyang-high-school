# 주의 DB와 색상 등급 후속 작업

사용자가 공식 인터넷 자료를 통한 주의 DB 보완을 요청했다. 2026-10-25 현재 아래 HTTPS 요청이 클라우드 프록시의 Tunnel connection failed: 403 Forbidden으로 차단됐다.

- https://www.fda.gov/cosmetics/cosmetic-ingredients/allergens-cosmetics
- https://eur-lex.europa.eu/eli/reg/2009/1223/oj/eng
- https://www.mfds.go.kr/

원문을 읽지 못했으므로 추측한 주의 정보나 등급을 CSV에 추가하지 않았다. 공식 사이트, Google 검색, Radix 디자인 사이트, GitHub API의 호스트 허용을 환경 초안에 저장했다. 설정 저장·게시 후 위 요청을 재확인하고 다음을 진행한다.

1. B 담당 자료 작업에서 성분의 정식명·동일 INCI, 국가, 대상 제품, 농도·사용 조건, 원문 URL과 확인일을 검토한다. EU/FDA 조건을 한국 규제라고 표시하지 않는다.
2. 기존 CautionRecord 열에 검증한 조건별 주의 사항을 기록한다. 원문 보존·라이선스·집계·생성 스크립트 영향도 검토한다.
3. 현재 데이터형에는 심각도 필드가 없다. 색상 등급이 필요하면 B/C가 근거 있는 판정 기준과 미확인 상태를 정의한 뒤 버전·어댑터·검사를 포함한 공통 변경을 한다. 농도를 모르면 조건 충족 여부도 확정하지 않는다.
4. 현재 유래 도넛을 안전성 도넛으로 바꾸지 않는다. 자료가 없거나 조건을 판단할 수 없는 성분을 초록(안전)으로 간주하지 않는다.

검증 계획: 근거/확인일·별칭·중복·자료 없음 검사, 조건별 주의 표시와 입력/DB 변경 시 결과 무효화, 전체 pytest·서버 검사. 현재 UI 변경의 Linux 결과는 32개 테스트와 서버 검사 통과, 실제 CPU 인공 라벨 OCR 검사 통과(자동 이름 21/26, 미확정 제안 포함 24/26). 실제 Windows와 촬영 사진은 미검증이다.
