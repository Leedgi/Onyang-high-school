# KCIA 선택적 확장 v1 — C 통합 요청

입력: 기존 CSV와 동일한 IngredientRecord 열의 kcia_ingredients.csv 및 kcia_sources.json. 처리: 기존 정식명 키로 교체/추가하고 별칭 충돌은 실패 처리. 공개 정의 검토 항목은 evidence_insufficient가 아닌 원인 코드로 구분해 이름 전용 수에서 승격한다. 출력: 기존 IngredientDatabase와 AnalysisResult를 그대로 사용한다. 실패: 생성물 체크섬 불일치·중복 별칭은 사용자에게 자료 오류로 알리고 이전 분석/PDF를 지운다. 자료가 없는 기존 저장소는 이전 로딩을 유지한다.

C가 선택적 로더, 파일 변경 지문, 동적 집계 화면/문서, 버전과 통합 검사를 반영한다. 기본 소스 270+28,077은 유지되나 현재 통합32,797, 검토394, 이름전용32,403이다. B 검사로 재생성 결정성·출처·숫자 보존 및 잘못된 기존 유래 재분류 없음을 확인한다. 공통 함수/필드/enum/의존성 변경 없음.
