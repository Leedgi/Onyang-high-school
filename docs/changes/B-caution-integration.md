# C 통합 요청: 주의 DB와 검증 명칭

기존 공개 함수와 CautionRecord 열은 그대로다. 30개 물질의 조건부 주의 63행, 환경 시험 3행, 검증 한글/구명칭 32행을 추가했다.

C가 반영할 공통 변경:

1. 선택적인 `caution_aliases.csv`(alias,inci,source_url,checked_on,source_cas)를 기존 INCI 레코드의 정확한 동의어로 연결한다. 출처·확인일을 검증하고 기존 다른 성분과 충돌하면 멈춘다. 새 유래 분류나 새 원료 레코드를 만들지 않는다. 한국어/INCI를 함께 입력해도 같은 canonical_name으로 중복을 제거해야 한다. `source_cas`는 원문 표기이며 여러 CAS를 하나로 확정하지 않는다.
2. 주의 CSV·별칭·환경 근거·검토 입력/집계가 바뀌면 DB 지문을 바꾸고 사진/확정/PDF를 재확인하게 한다. 가능하면 집계 파일 체크섬과 CSV를 함께 검증한다.
3. v1 결과의 reason 접두사 `[인체·...]`와 `[환경·생분해성]`는 표시 묶음에만 쓴다. 기존 접두사 없는 주의 레코드도 버리지 않는다. 새 severity·안전 등급 필드를 만들지 않는다.
4. UI/PDF가 등록된 주의의 농도·제품·사용 조건·출처·확인일을 보존하고, 데이터가 있는데도 무조건 ‘자료 없음’으로 표시하지 않게 한다. 완제품 영향 판단 보류와 pH 확인 불가는 유지한다.
5. 신규 CSV는 선택적 자료 형식 v1이며 기존 CSV/공개 자료형 변경은 없다. 구 프로젝트에서 파일이 없으면 기존 로딩 동작을 유지한다.
