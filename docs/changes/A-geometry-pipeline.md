# C 통합 요청: 방향·곡면 보정 버전

A의 공개 함수·자료형은 바꾸지 않았다. core.scan의 내부 pipeline_version은 5다. UI가 같은 사진의 과거 결과를 재사용하지 않도록 shared/contracts.py의 PIPELINE_VERSION을 새 값으로 바꾸고 입력/후보/DB/사진 변경 무효화 검사를 수행해 주세요.

추가 의존성이나 모델은 없다. CPU 전체 방향 비교와 조건부 곡면 대안 때문에 처리 시간은 늘 수 있다. 회전 합성/곡면 합성 검사를 실제 촬영 사진 성능이라고 설명하지 않는다. 첨부 원본 파일이 실행 환경에 없다는 제한을 유지한다.
