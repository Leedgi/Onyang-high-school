## 실제 검사

- 전체 pytest 59개. 방향별 실행 실패/오도하는 첫 heading, 곡선 원본 보존, 숫자 다른 명칭, 생성 결정성, 확장/기본 DB 변경 검증, 이전 PDF 제거, 기존 자료만 있는 프로젝트 호환 등을 포함한다.
- Streamlit HTTP health/page 검사 통과. Chromium 1280/390px에서 쌀겨수·호호바에스터·글리세린·포타슘하이드록사이드·D5를 직접 입력해 단일 확인, 유래 묶음, 환경 주의, 출처와 그래프를 포함한 PDF, 수정 시 무효화를 확인했다. 사진 OCR 결과로 제시한 입력이 아니다.
- 실제 CPU 모델 scripts.check_auto_ocr 통과. 인공 전체 라벨26개에서 단순 전체 이미지 방식은7개, 자동 영역 인식 원문은21개, 미확정 제안은22개 이름 일치. 같은 라벨의 180도 회전에서 선택 각도180, 원문21/제안22개; 원통 압축·행 휨을 합성한 라벨에서도 곡면 대안 채택 후 원문21/제안22개. 각67.7~70.9초(이 클라우드). 결과는 artifacts/auto-ocr-comparison.json과 ocr-geometry-integrated.json에 로컬 저장하며 인공 이미지 자료만 사용했다.
- A 단계에서 같은 구 DB로 비교한 곡면 합성 시험은 원문19→21, 미확정 제안21→23개였다. 새 명칭 사전에는 유사한 후보가 더 많아 통합본은 일부 오타를 검토 상태로 남기므로 제안 수치를 이전 결과와 같은 사전의 정확도 향상으로 해석하면 안 된다. 미확정 제안은 사용자 확인을 대신하지 않는다.
- 원본 PDF의 셀 경계 기반1,578쪽/22,021행 추출을 다시 실행했고 생성 CSV SHA-256이 일치했다. 144개 정의 중 식물112/석유6/기타11/공급원미상15개. 기존 확정 유래의 반대 분류 변경은 없고 충돌별칭242건은 격리했다. 통합32,797개, 정확키57,706개, 검토394개/이름전용32,403개다.

## 범위와 제한

첨부 사진은 대화에서 보았지만 도구로 읽을 원본 파일 경로가 없어 실제 OCR에 투입하지 못했다. 위 결과는 촬영 사진의 일반 성능 보증이 아니다. 사진에서 직접 옮긴26개 명칭 조회는 모두 연결됐지만 식물성2/기타4/공급원확인필요20개였다. 이름 등록과 제조 유래 확인은 별개이며 공급사 근거 없이 강제 식물성/석유계 분류를 하지 않는다. 상세 검토 범위와 출처는 data/README.md를 따른다.

Windows 실기 검사는 수행하지 않았다. GitHub Windows workflow 결과와 Linux 검사를 구분한다. 실행 의존성 추가는 없으므로 기존 설치 환경은 최신 파일 갱신 후 run_windows.bat으로 재시작하면 된다. 공개 배포 작업은 포함하지 않았다.
