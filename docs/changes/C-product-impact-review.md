# pH·인체 영향·환경 영향 경고의 후속 근거 검토

사용자는 2026-10-30 제품별 산성도와 인체·환경 영향 경고를 요청했다. 성분명·순서만으로 완제품 pH를 계산할 수 없고, 함량·제품 종류·노출 조건이 없으면 위험성도 제품별로 확정할 수 없다.

## 이번에 넣은 내용

- UI ‘주의 정보’와 PDF에 pH 확인 불가 / 인체 영향 판단 보류 / 환경 영향 자료 부족을 명시한다. 이는 위해성 평가나 안전 등급이 아니다.
- 기존 DB의 BUFFERING 기능이 있는 성분을 보여주되, 2019 기능 표기를 완제품 pH나 자극성의 근거로 쓰지 않는다. 산과 염기가 함께 있어도 산성·염기성·중성을 임의 확정하지 않는다.
- 기존 AnalysisResult.cautions에 근거 있는 레코드가 있으면 UI/PDF에 출처·확인일·제품·농도·사용 조건을 함께 표시한다. 현재 cautions.csv는 여전히 빈 자료이다. 새 인체·환경 주의 데이터를 추가했다고 주장하지 않는다.
- 석유계/식물성, 실리콘/폴리머라는 이름만으로 독성이나 생분해성을 분류하지 않는다. 임의의 빨강/주황/초록 등급을 만들지 않는다.

## 실제로 막힌 출처 확인

다음 HTTPS 요청은 환경 프록시 `Tunnel connection failed: 403 Forbidden`으로 차단됐다. 원문을 읽지 못했으므로 아래 URL은 새 주의 정보의 인용 근거로 쓰지 않는다.

- https://www.fda.gov/cosmetics/cosmetic-ingredients/alpha-hydroxy-acids
- https://www.fda.gov/cosmetics/cosmetic-ingredients/allergens-cosmetics
- https://echa.europa.eu/hot-topics/cyclic-siloxanes
- https://eur-lex.europa.eu/eli/reg/2024/1328/oj/eng
- https://www.epa.gov/caddis/ph

기존 허용 도메인 초안을 보존하며 echa.europa.eu와 www.epa.gov를 추가 저장했다. 초안 저장은 실행 환경 적용·게시와 별개다. 사용자 설정 저장·게시 후 실제 접속을 재확인해야 한다.

## B 자료와 C 통합의 다음 단계

1. 접속이 가능해지면 원문·적용 국가·시점·농도·제품 종류·노출 조건·예외를 검토하고 정식명/INCI를 대조한다. FDA/EU 조건을 한국 법규로 표현하지 않는다.
2. B가 검증한 성분별 주의와 환경 시험자료를 추가한다. pH는 제조사 공개값 또는 측정값을 입력받을 규격이 별도로 필요하다.
3. C가 제품 정보와 판정 조건의 새 필드가 필요한지 검토하고, 필요하면 공통 버전·호환 어댑터·검사를 먼저 추가한다. 미공개 농도·모르는 조건을 충족한 것으로 취급하지 않는다.
4. 실제 위험성 평가, 생분해성·잔류성·생물농축성·수생독성은 구분해 표기한다. 자료가 없으면 개별 성분의 위해 경고를 만들어내지 않는다.
