# B 주의 자료 통합

2026-10-30. B의 c5e674e 자료 변경을 C가 공통 로더·UI·PDF에 통합했다. 공개 함수와 CautionRecord는 v1을 유지한다.

- 입력: 검증한 한글/INCI/구명칭 → 처리: 기존 INCI 레코드에 선택적 동의어 연결 → 출력: 같은 canonical_name과 한 번의 주의 레코드 → 실패: 다른 성분과 표기가 충돌하거나 출처/확인일이 없으면 오류. 기존 파일이 없는 프로젝트는 기존 동작을 유지한다.
- 이름 전용 레코드는 여전히 유래 확인 필요다. 270개 대표/28,077개 이름 레코드 집계는 그대로이며 새 유래 분류는 만들지 않았다.
- 주의·검증 별칭·환경 시험·검토 입력·출처 집계를 DB 지문에 포함한다. 파일이 변경되면 기존 확정 결과·PDF를 폐기한다. 생성물의 SHA-256이 집계와 다르면 주의 데이터 로딩을 거부한다.
- 기존 reason의 접두사를 표시 그룹에만 이용한다. 화면에서 인체 주의와 환경 시험을 나누고 실제 주의·사용 안내·자료 시점·확인일·국가를 보여준다. 물질 동일성·위험 판단 한계는 접지 않고 표시한다. 자세한 제품/농도 조건과 원문 링크를 펼쳐 볼 수 있다. 접두사 없는 기존 레코드도 유지한다.
- PDF는 동일 AnalysisResult의 주의·농도·제품·국가·출처·확인일을 그대로 담는다. 완제품 pH와 안전성·환경 피해 점수는 계산하지 않는다. 매칭되지 않은 성분은 자료 없음이지 안전함이 아니다.
- 전체 지침의 ‘주의 DB가 비어 있음’이라는 초기 상태를 새 집계로 수정했다. 추천·제품 비교는 여전히 미구현이다.

검증: Linux Python 3.12 전체 pytest 49개, 서버 검사·pip check·CPU 인공 라벨 OCR 검사 통과. 한국어/INCI 중복 제거, 원문 입력 보존, 유래 불변, 별칭 충돌 거부, DB 변경 시 PDF 해제, 체크섬 불일치 거부, UI/PDF의 시험 수치·농도·자료 시점 보존을 검사했다. Chromium 1280/390px에서 주의 카드·조건·원문 링크·PDF 다운로드를 확인했다. 실제 Windows와 촬영 사진의 일반 성능 검사는 아니다.

이전 차단 기록의 후속 상태: FDA와 PubChem은 이번에 본문을 읽을 수 있었다. ECHA 원사이트 403과 EUR-Lex 빈 202는 계속되어 최신 법규는 입력하지 않았다. 기존 docs/changes/C-caution-evidence.md와 C-product-impact-review.md는 당시 관찰 기록이며, 이번 데이터 범위는 data/caution_sources.json과 docs/b/caution-db.md를 기준으로 한다.
