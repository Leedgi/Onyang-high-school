# 초록색 화면과 도넛 그래프

- 제목과 브라우저 제목: 친환경 제품 성분 정보 분석.
- 화면 색은 Radix Colors 공식 Sage/Grass 색상표를 인터넷으로 확인해 참고했다.
  https://github.com/radix-ui/colors/blob/main/src/light.ts
  확인일: 2026-10-25. Google 검색과 Radix 웹사이트는 클라우드 프록시 403으로 접근되지 않았다. 공개 원본 파일은 HTTPS 200으로 읽었다.
- 세이지 배경 #f7f9f8, 짙은 초록 #203c25, 버튼 #2a7e3b. 외부 폰트·이미지·스크립트는 추가하지 않았다.
- 입력: B의 AnalysisResult → 처리: count_ratio.values를 그대로 Altair 도넛에 표시 → 출력: 유래 범례·비율 툴팁·총 성분 수 → 실패: 빈 목록은 기존 안내를 유지한다. 확인 필요도 분모에 포함한다.
- 초록·주황·빨강 주의 등급은 적용하지 않았다. 현재 cautions 자료와 등급 기준이 없고, 원료 유래를 안전성 등급으로 바꾸면 잘못된 안내가 된다. 대신 결과에 ‘주의 등급 · 자료 부족’을 표시한다. B가 근거·적용 조건·검토일과 분류 기준을 마련한 후 C와 공통 규격을 합의해야 한다.
- 제품의 친환경성·안전성 인증 서비스가 아니라는 설명을 제목 아래 표시한다.
- A/B 코드와 공통 v1 규격은 변경하지 않았다. 최초 화면·도넛·미확인 포함·등급 자료 없음·수정 시 그래프 해제 회귀 검사를 추가했다.

## 전체 초록 테마·도넛 개선 (2026-10-25)

이번에는 Google 검색(`Radix Colors grass sage green palette`)과 공식 https://www.radix-ui.com/colors 및 공개 색상 원본을 HTTPS 200으로 확인했다. 이전의 접속 차단 기록과 구분한다.
배경 #f0f7f0, 업로드/선택 영역 #e0eee1, 버튼 #2a7e3b, 글자 #1a3524로 초록색을 넓혔다. CSS와 Streamlit 기본 테마에 함께 적용한다.

입력은 동일 AnalysisResult이다. 유래 비율은 재계산하지 않고 원호와 내부 % 레이블에 그대로 전달한다. 화면 크기에 맞는 반지름과 상하좌우 여백으로 잘림을 방지한다. Streamlit 프런트엔드에서 숫자형 padding을 처리하지 못하는 오류를 실제 Chromium 검사로 찾아 객체형 여백으로 수정했다. 0% 조각은 레이블을 생략하고 비율 표에서 확인할 수 있다.

기본 성분 표는 성분·유래·기능 세 열만 표시한다. 확인 필요 원인·근거·출처는 접힌 상세 영역과 원래 다운로드 자료에서 확인할 수 있다. 공통 분석 규격과 OCR·DB는 바꾸지 않았다.

Linux 검사: 전체 pytest 32개, 서버 검사, 실제 CPU 인공 라벨 OCR 연결 검사 통과(자동 이름 21/26, 미확정 제안 포함 24/26). Chromium의 1280px·390px·320px 화면에서 입력→확인→그래프 렌더링 및 가로 화면 범위, 배경색을 확인하고 모바일 스크린샷에서 내부 %를 직접 확인했다. Windows 실제 검사는 수행하지 않았다.
