# 데이터 검토 원칙

이 학생 프로젝트는 실자료 CSV만 읽는다. 가상 계산 예제 DB나 모드 선택은 포함하지 않는다.
이름 사전 등재와 제조 원료·안전성·최신 규제 검토는 서로 다르다.

## 현재 자료 범위

| 자료 | 레코드 수 | 용도 |
| --- | ---: | --- |
| `ingredients.csv` | 270 | 대표 성분 한글명·INCI·기능·분류 근거 |
| `ingredient_names.csv` | 28,077 | 추가 INCI 이름·식별자 검색. **유래는 모두 확인 필요** |
| `curation.csv` | 270 | 한글 매핑·분류 종류. 생성 스크립트 입력 |
| `source_evidence.csv` | 270 | 조회한 원문 정의·기능·CosIng 참조 번호 |
| `sources.json` | — | 원본 URL·커밋·SHA-256·확인 날짜·자료 범위 |

대표 성분은 석유계 5, 식물성 63, 기타 34, 확인 필요 168개다.
추가 사전과 이름·별칭 충돌을 정리해 총 28,347개 레코드로 읽는다.
전 세계 모든 화장품이나 실제 제조 유래를 검증한 것은 아니다. 유래 검토용 한글 매핑은 270개이며, 별도 주의 자료의 검증된 한글/구명칭 연결은 아래에 설명한다.

### 출처와 검토 범위

1. [CosIng database finder의 2019 공개 스냅샷](https://github.com/walkowskis/CosIng_database_finder/tree/d3dbd5644813ef6c1bff59b6b075fec54a1eaaff)
   - EU CosIng 자료를 포함한 **비공식 공개 미러**, 스냅샷 날짜 2019-03-16.
   - SQLite에서 선택한 270개 INCI의 참조 번호·정의·기능을 직접 조회했다.
   - 성분 정의로 식물 오일·왁스·추출물, 석유 탄화수소, 물·무기물·실리콘·동물 유래를 구분했다.
   - 공급 원료가 특정되지 않는 화합물은 확인 필요다. 정의가 빈 1,2-헥산다이올은 근거 부족으로 남겼다.
   - **최신 공식 사이트 검토나 현행 규제 확인이 아니다.** 금지·제한·농도 열은 가져오지 않았다.
2. [Cosmetic Ingredients Dataset (Lite), BEAUTEE](https://github.com/beauteeru/cosmetic-ingredients-dataset/tree/ad1d9afad3f1a721873878b83fbd9f674d628c9e)
   - MIT 라이선스의 제3자 사전. 이름·CosIng ID·CAS·EC·PubChem ID를 제공한다.
   - 원본 28,354행에서 기존 성분·별칭 및 같은 이름의 중복을 제외해 28,077행을 추가했다.
   - 유래·안전성 자료가 아니므로 모든 추가 항목을 `evidence_insufficient`로 둔다.
   - 식별자 전체를 공식 원문과 일일이 대조한 것은 아니므로 자동 규제 판정에 쓰지 않는다.

원문 정의의 줄 끝·앞뒤 공백만 정리해 근거 CSV에 보존한다.
확인 날짜 2026-10-24는 위 **고정 자료를 조회한 날짜**다. 공급사·제품 확인일이나
2019 자료의 갱신 날짜가 아니다. 한글 별칭은 교육용 매핑이며 공식 국문 명칭 인증이 아니다.
라이선스와 출처 표시는 [NOTICE](NOTICE.md)와 `licenses/BEAUTEE-MIT.txt`에 보존했다.

### 유래 분류의 범위

- 석유계 5개는 스냅샷 정의의 석유/탄화수소 정제 경로를 근거로 분류했다.
- 식물성은 INCI 원료 정의의 식물 유래다. 추출 용매·제품 부원료까지 식물성이라고 보증하지 않는다.
- 물·무기물·실리콘·비즈왁스·라놀린은 기타다. 기타가 천연·무해라는 뜻은 아니다.
- 글리세린·스쿠알란·지방알코올·에스터 등은 공급 원료와 제조 경로를 확인하지 못하면 확인 필요다.
  합성이라는 이유만으로 석유계라고 정하지 않는다.
- 사전 등재는 사용 허용·안전성·친환경성 검증이 아니다. 주의 DB는 아래의 별도 검토 자료를 사용한다.

## 실자료 추가 절차

1. 제조사 원료 자료 또는 공식 원문에서 실제 유래와 적용 조건을 확인한다.
2. 이름, 별칭, 분류 이유, HTTPS 출처 URL, 확인 날짜를 기록한다.
3. 제조 방식에 따라 유래가 달라지거나 근거가 부족하면 `확인 필요`로 둔다.
4. CSV 필드에 쉼표가 있으면 큰따옴표로 감싼다. 별칭과 기능 태그는 `|`로 구분한다.
5. `python -m pytest`와 실제 화면으로 확인하고 별도 검토 뒤 반영한다.

고정 자료 재생성 명령(저장소 폴더의 PowerShell):

```powershell
.\.venv\Scripts\python.exe -m scripts.build_ingredient_data
```

원본의 SHA-256을 검증해 CSV를 생성한다. 원본은 `.cache/ingredient-sources`에만 보관한다.
재실행일을 검토일로 자동 기록하지 않는다. 자료가 바뀌면 새 원문을 검토하고 커밋·체크섬·검토일을 함께 갱신한다.
앱 실행에는 이 다운로드가 필요 없다. 생성 CSV를 직접 고친 경우 재생성 전에 변경을 별도로 보존한다.

`uncertainty_reason` 코드:

| 코드 | 의미 |
| --- | --- |
| db_missing | DB에 등록되지 않음 |
| name_unresolved | 이름 대조가 확정되지 않음 |
| origin_uncertain | 성분명은 알지만 실제 원료 유래가 불명확함 |
| evidence_insufficient | 근거 자료가 부족함 |

출처·날짜가 없는 실자료는 `확인 필요 / evidence_insufficient`만 허용한다.
URL 형식 검사는 원문 검토나 최신성 검증을 대신하지 않는다.
현재 주의 정보는 조회만 하며, 농도나 국가별 규제의 준수 여부를 자동 판정하지 않는다.

대체 성분과 제품 CSV는 향후 규격을 위한 빈 틀이다. **추천·제품 비교 알고리즘은 아직 미구현**이다.
값을 넣는 것만으로 화면 추천이 활성화되지는 않는다. 로더·조건 검사·테스트를 먼저 연결해야 한다.

## 주의·인체·생분해성 검토 DB (2026-10-30)

- `cautions.csv`: 30개 물질(인체 주의 27, 환경 시험 3)에 대응하는 한글·INCI·검증된 구명칭 63행. 이름 표기별 중복 투영이며 63개의 서로 다른 물질이 아니다.
- `environmental_evidence.csv`: D4·D5·D6의 시험법·기간·시험 농도·평가 지표·수치·한계·출처 3행.
- `caution_aliases.csv`: KCIA 검색에서 INCI·CAS와 대조한 한글/구명칭 32행. 유래 근거를 추가하거나 유래 분류를 바꾸는 자료가 아니다.
- `reviewed/caution_review.json`: 검토 입력, 출처 원문 일부, 자료 시점, 원문 응답 체크섬, 명칭 대조 기록.
- `caution_sources.json`: 범위·행 수·생성물 체크섬·출처 집계. 기존 `sources.json`의 2019 유래 자료와 분리한다.

FDA 소비자 안내는 AHA(2022-11-22), BHA(2022-02-25), 알레르겐(2026-10-09) 원문을 읽었다. 피부 반응은 개인 감작·농도·제형·사용 부위 등 조건에 따라 달라지므로 완제품 안전성 등급을 만들지 않는다. 미국 안내를 한국 법규라고 표시하지 않는다.

환경 수치는 PubChem/HSDB가 정리한 과거 시험이다. D4는 OECD 310, 10 mg/L, 29일에 이론적 CO2 발생량의 3.7%; D5는 OECD 310, 20 mg/L, 28일에 0.14%; D6는 OECD Draft Guideline 310, 28일에 생분해도 4.47%(요약 원문에 농도 미기재)이다. 최신 규제나 이 제품의 배출 피해를 확인한 것이 아니다. D4는 INCI에 복수 CAS가 연결되므로 원료가 CAS 556-67-2인지 별도로 확인해야 한다. 휘발·가수분해 등 다른 소실 경로도 있어 ‘영원히 분해되지 않음’으로 표현하지 않는다.

검토 입력만 재생성하려면 `python -m scripts.build_caution_data`를 실행한다. 네트워크 없이 검토 입력에서 생성하며, 새 원문 검토일을 자동으로 바꾸지 않는다. PDF/화면에는 기존 AnalysisResult.cautions 연결점을 사용한다. 근거를 검토하지 않은 다른 향료·실리콘·고분자에 같은 경고를 추정 적용하지 않는다. 미일치·자료 없음은 안전 판정이 아니다.
